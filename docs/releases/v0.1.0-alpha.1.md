# Method Council v0.1.0-alpha.1

This is the first source-only public alpha of Method Council: a provider-neutral
protocol for applying documented analytical methods in separate passes and
retaining one traceable synthesis.

## Included

- Eight source-backed methods and six activity profiles.
- Deterministic validation for routes, artifacts, evidence, status, recorded
  runs, acceptance evidence, and release manifests.
- A Codex-subscription-first skill and local project projection.
- Five hardened, commit-bound Codex acceptance bundles.
- Original diagrams, mark, social-preview artwork, and representative imagery.
- Preview-only, disabled contracts for Claude Code and Gemini CLI.
- A candidate-bound local release gate that reruns its registered checks before
  deriving eligibility.

## Try it

```bash
git clone https://github.com/jremick/method-council.git
cd method-council
uv sync --frozen --all-groups
uv run --frozen method-council validate
uv run --frozen python scripts/sync_codex_skill.py check
```

Then open Codex from the repository and ask it to use `$method-council`.

## Alpha boundaries

- This release is for inspection and experimental use, not production reliance.
- Method usefulness has not passed blinded baseline or independent practitioner
  evaluation.
- Recorded model runs are `INCOMPLETE / CORRELATED` and use an
  `unsigned-local-recorder` envelope.
- Non-Codex adapters are disabled and unverified.
- Interfaces and schemas may change without migration support before beta.
- No package is published to PyPI; GitHub's source archives are the only release
  downloads.
