# Support

Method Council is experimental public-alpha software maintained on a best-effort
basis.

- Use [GitHub Issues](https://github.com/jremick/method-council/issues) for
  reproducible bugs and bounded feature requests.
- Use [GitHub private vulnerability reporting](https://github.com/jremick/method-council/security/advisories/new)
  for suspected security issues.
- Do not use public issues for secrets, private prompts, exploit details, or
  unrelated Codex account and subscription support.

There is no response-time guarantee, compatibility guarantee, implementation
consulting, or support for disabled preview adapters. GitHub Discussions and the
wiki are intentionally disabled.
