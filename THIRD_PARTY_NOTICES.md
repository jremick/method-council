# Third-party notices and source acknowledgements

Method Council is a clean-room implementation. It does not copy source code,
prompt text, method text, or visual assets from the projects and publications
listed below unless a future notice explicitly says otherwise.

## Concept-level inspiration

The high-level idea of coordinating multiple analytical passes was informed by:

- **Council of High Intelligence**, 0xNyk,
  <https://github.com/0xNyk/council-of-high-intelligence>, MIT licensed at the
  time of review. Method Council uses an original architecture, method model,
  wording, schemas, implementation, and visual system. This acknowledgement does
  not import that project's MIT-licensed material into this repository.

## Method and quality sources

Method records cite primary or authoritative publications from the Office of the
Director of National Intelligence, United States Central Intelligence Agency,
NASA, and Homes England. The threat model separately cites public security
guidance including NIST and OWASP material.

Those publications are references for provenance and analysis quality. Their
names, titles, and links are factual citations, not endorsements, certifications,
or claims that this project is an official implementation. Source documents are
not vendored in this repository. See [docs/SOURCES.md](docs/SOURCES.md) and each
method record for the exact source, adaptation, and claim boundary.

## Software and assets

Runtime and development dependencies retain their own licenses; dependency
metadata is recorded by the project lockfile and package manifests. No
third-party image, icon, font file, screenshot, or generated bitmap is included
in the initial design foundation. The SVG assets in `assets/` are original,
code-native work created for Method Council.

If third-party material is added later, this file and the Apache `NOTICE` file
must be reviewed before distribution.
