# Live Codex acceptance tasks

These are intentionally public, synthetic engineering cases for repeatable
acceptance runs. They contain no user prompt, private repository context, or
credential. A run manifest records only the task digest; the readable case stays
here so reviewers can understand what was tested.

Each task exercises a different profile and failure boundary. The
`forecast-plugin-ecosystem` case also closes initial live coverage for
Alternative Futures and Indicators/Signposts. Passing the run verifier means
the resulting artifact bundle is internally consistent. It does not establish
factual accuracy, independent corroboration, general method fidelity, or
usefulness across a task distribution.
