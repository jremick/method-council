# Competing Hypotheses Analysis

Status: **preview**

Use this method for competing explanations of the same observations. It arrays the same evidence
against every hypothesis and emphasises disconfirmation, diagnostic value, missing expected
evidence, and sensitivity.

## Procedure shape

1. Frame the condition to explain and enumerate distinct hypotheses.
2. Inventory evidence once and expose dependencies.
3. Populate a complete evidence-by-hypothesis matrix.
4. Find discriminating evidence and test missing expected evidence.
5. At intensive depth, test sensitivity and define monitoring indicators.
6. Report the leading and weaker live hypotheses with limitations.

Matrix labels and tallies are not probabilities. An unavailable observation is not automatically
evidence against a hypothesis.

## Adaptation and limits

This preview is inspired by the public Analysis of Competing Hypotheses procedure in the CIA
primer. It adds machine-readable evidence binding and dependency tracking. Formal ACH fidelity,
hypothesis completeness, and domain adequacy have not been independently established; the project
therefore does not label this a validated ACH implementation.
