# Indicators and Signposts

Status: **preview**

Use this method to convert hypotheses, scenarios, assumptions, or risks into observable change
conditions. It is designed for periodic reassessment, not a one-time vote on which future is true.

## Procedure shape

1. Frame the states and monitoring horizon.
2. Derive observable signs for and against each state.
3. Check direction, timing, diagnosticity, correlation, ambiguity, and manipulation risk.
4. Define collection ownership without initiating side effects.
5. Set a checkpoint and reassessment rule.

Indicator counts do not calculate probability. Missing observations must distinguish unavailable
data from an event that was observable but did not occur.

## Adaptation and limits

The workflow is adapted from the CIA's public Indicators or Signposts of Change method. Method
Council adds source binding, collection constraints, and explicit correlation checks. It does not
claim CIA training, certification, endorsement, or independent method fidelity.
