# Causal Factors Analysis

Status: **preview and unevaluated**

Use this method after a failure, defect, incident, or recurring outcome. It reconstructs what
happened, tests causal links, separates symptoms from contributing and root factors, and ties each
corrective action to the condition it should change.

## Procedure shape

1. Define the event and its boundary without assuming the cause.
2. Build a time-ordered record and preserve evidence gaps.
3. Map candidate causal links and alternative explanations.
4. Separate direct, contributing, systemic, and control factors.
5. Link corrective actions to supported causes.
6. At intensive depth, define effectiveness and recurrence checks.

A neat story is not enough. Unsupported links remain assumptions or unknowns, and a causal result
should be `INCOMPLETE` when the event record cannot distinguish important alternatives.

## Adaptation and limits

This is a domain-neutral adaptation of NASA's public closed-loop root cause guidance. It is not a
regulated safety, personnel, legal, or mishap investigation, and it does not confer NASA process
compliance. Independent fidelity and usefulness evaluation are still required.
