# Alternative Futures Analysis

Status: **preview**

Use this method when complexity and uncertainty make a single forecast unsafe. It constructs
several plausible futures, examines how decisions fare in each, and defines indicators for later
reassessment.

## Procedure shape

1. Bound the focal issue and time horizon.
2. Identify evidence-informed forces and critical uncertainties.
3. Test and select organising axes or document another scenario structure.
4. Build coherent futures with assumptions and causal paths.
5. Challenge coverage and preferred-future bias.
6. Test strategy robustness and define observable indicators.

The scenarios are possibilities, not predictions or probabilities. A two-axis matrix is a useful
structure only when the axes are critical, uncertain, and sufficiently independent.

## Adaptation and limits

The workflow is adapted from the CIA primer's public Alternative Futures Analysis. Method Council
adds typed assumptions and report checkpoints. It does not claim exhaustive coverage, forecast
calibration, CIA training, certification, or endorsement. Independent fidelity review remains open.
