# Outside View / Reference Class Check

Status: **preview and unevaluated**

Use this method when a plan, estimate, forecast, or option is mostly justified from its own details.
It asks what actually happened in comparable completed cases, then checks whether the current
expectation sits inside a defensible range.

## Procedure shape

1. Define the forecast target and current maturity.
2. Set comparison rules before inspecting outcomes.
3. Test whether the cases are genuinely comparable.
4. Establish the observed range without inventing precision.
5. Compare the inside view and state the decision implication.
6. Expose data and selection limits; at intensive depth, test sensitivity and plan refreshes.

If there are too few reliable comparable cases, the useful result is an explicit `INCOMPLETE`, not
a confident number.

## Adaptation and limits

This generalises public Homes England guidance beyond infrastructure cost and schedule. It is not a
calibrated reference-class forecast unless the data and analysis support that claim. Independent
fidelity and usefulness evaluation are still required.
